## About

A single line roasting the most boring object in the kitchen — the fridge —
for the [make.fun](https://make.fun/c/u-suzy-one-line-one-laugh-roast-your-fridge-f1063521)
competition "One Line, One Laugh: Roast Your Fridge". The entry is one line of
at most 200 characters: it has to be really about a fridge, find a specific
detail worth mocking, turn on a twist, and read well out loud.

## The entry

> My fridge is the worst roommate I've ever had: it eats my leftovers, hums at 3 a.m., charges me rent in electricity, and never does the dishes.

## How to run

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (or to `$OUTPUT_DIR/entry.txt`
when that variable is set) and prints it with its character count.
